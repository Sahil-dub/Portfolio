# Sahil Dubey Portfolio

Phase 0 foundation for a recruiter-focused personal portfolio built with
Next.js, TypeScript, Tailwind CSS, Framer Motion, and Vercel deployment in
mind.

## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Current Scope

- App Router foundation
- Reusable layout components
- Basic UI primitives
- Placeholder content data
- Simple homepage shell
